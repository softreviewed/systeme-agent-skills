# Start with one useful task

Installation supplies the whole playbook: platform operations, page design, copy, email writing, troubleshooting and an official-source search helper. It does not install credentials or enable paid features.

## Check readiness without changing the account

1. Confirm this skill is discoverable in the agent's supported skill directory. Keep one installation. Run the optional `scripts/check_install.py` helper for file completeness, or inspect its required files without Python.
2. Discover whether a Systeme.io connector or authenticated dashboard browser is available. Do not request an API key in a public message or save it in this folder. Use the client's supported secure connection flow. Refer to current official connection instructions rather than guessing a universal setup command.
3. If connected, perform one supported read-only inventory request in the selected account. A listed tool is not proof of authentication. Do not fetch the entire customer list just to test readiness.
4. Report: skill files complete/incomplete; planning ready; account read succeeded/not tested/failed; browser editing available/not tested; next task. Do not mark sending, publication or billing ready merely because a read succeeded.
5. Start the user's requested task immediately. If no task is specified, offer to draft one relevant page or welcome email. Do not create a sample funnel, send a test to a real contact or enable automation just to demonstrate setup.

## Ready at installation

Audience brief, page structure, copy, design plan, email drafts and platform guidance need no account connection. Current product facts still require a current source check. Actual edits need the user's connected account and available supported tools.

## One request, selective guidance

| Request | First guides | Later only if needed |
|---|---|---|
| Build a course signup page | Audience/copy + funnels | Visual design, course access, email writing, quality review |
| Write a welcome sequence | Email writing | Platform email + automation when implementing |
| Fix cramped mobile text | Visual design | Relevant website/funnel editing route |
| Give a customer course access | Courses/communities | Tool routing; troubleshooting on failure |

Load the relevant file at the current stage. Keep task notes in the user's project, never edit the installed skill with customer data. No skill can guarantee that the host agent forgets loaded text; selective reading reduces unnecessary context, while the client controls memory and caching.
