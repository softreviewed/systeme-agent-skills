# Email marketing and delivery

Distinguish a one-time newsletter from a timed campaign. Identify the approved audience, sender, offer, send time/timezone and success condition. Search `sender address`, `authenticate domain`, `campaign`, `newsletter` and `test email`; read the current article before configuration.

For campaigns, map each email to a reader need, the preceding message and its delay. Create/review the copy and links before activation. Campaign timing follows actual configuration; do not assume all delays run from signup. Back up copy before switching editors because that can discard content.

For newsletters, saving a draft, scheduling it and sending it are separate actions. User authorization to write copy does not authorize a broadcast. Confirm an ambiguous audience or time before sending; preserve unsubscribed/suppressed contacts.

Authenticate the sender using the current account-provided records and verify sender status. Do not replace unrelated DNS settings or imply a paid external email provider is required without evidence. Check opt-in and unsubscribe behavior appropriate to the user's setup.

Test only to an authorized address. Check rendered links, mobile layout, variables and footer. A successful test request does not prove inbox placement for the whole list. Investigate failures using authentication, campaign state, trigger, contact status and delivery evidence before proposing retries or another provider.
