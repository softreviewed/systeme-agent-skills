# Websites, blogs and link-in-bio pages

## Choose the route

Inspect which builder the account exposes. The dedicated Websites feature manages multiple pages; blogs suit regular articles; funnels can serve a small linked-page site. Do not convert an existing site between these routes without a reason and a URL-preservation plan.

For a link-in-bio page, start with the visitor's next action: book, download, watch, buy or join. Gather the real destinations and brand assets. Recommend one main action with a short set of supporting links, clear labels and comfortable mobile touch targets. This is our layout recommendation, not a special native product claim.

## Build

Read the current [website builder article](https://help.systeme.io/article/4526-how-to-create-a-website) and check the account allowance before calling the result free. Use the account's available builder and domain; never detach a live domain merely to create a new draft. Preserve its homepage assignment. Website global styles affect every page; scope changes deliberately.

Configure page copy, form destination and navigation. For email capture, continue into the email/automation guides. Inspect heading hierarchy, descriptive title, useful description, readable contrast, image descriptions and correct CTA destinations. Review visibility settings: a page hidden from search should not be reported as search-ready. Avoid keyword stuffing and ranking promises.

## Verify

Check the saved page and the public URL separately, including mobile spacing, button contrast, navigation and form behavior. Draft pages need publishing before visitors can see them. Trigger a test opt-in only to a user-approved test address; verify its record and intended follow-up. Never assume editor preview equals live output.
